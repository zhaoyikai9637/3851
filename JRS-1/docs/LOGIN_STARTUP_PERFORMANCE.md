# Login initialization and HR startup - 2026-11-03

The login form declares POST explicitly and ships with a disabled credential fieldset. Only the final initialization step, after input and submit handlers are installed, enables the controls. A delayed or failed script leaves the form disabled with reload guidance. The fieldset has neutral styling so the existing login/register layout, validation, password reveal and return links are retained.

The integrated shared-session repository joins session, account and current canonical HR status in one parameterized query. Malformed JSON, noninteger account IDs, wrong modules, missing accounts, expiration and inactive HR are rejected. A verified canonical identity is reused only inside that request; roles and revocation are never cached between requests. Standalone repository behavior remains compatible.

Native HR boot obtains the current user, CSRF token and workspace together, removing its separate auth/me request. The GET response is authenticated and no-store. It uses the identity verified for that request; mutation responses still reload the user when needed so profile edits do not return old fields. Independent canonical-person refresh and template preparation run concurrently before the coherent workspace snapshot.

Validation: 188 integrated tests, 136 React tests, 183 communication server/API tests, 125 native HR tests and production builds pass. A notification-loading test now waits for its mocked request callback to be installed before resolving it; its assertions are unchanged. Edge tests with delayed and failed scripts verify disabled controls, no credential URL, normal Enter login, registration and mobile width. Independent real-MySQL tests verify malformed sessions, expiry and immediate HR deactivation. HR browser checks verify one startup fetch and an actual CSRF-protected draft save without real mail. QA full-page readings were about 6.5-8 seconds; public before/after timings are recorded privately after deployment. This does not guarantee instant rendering or eliminate infrastructure/network delay.
