## 如何复验

安装依赖后 `npm test` 或 `npm run test:jest` 不需要真实 MySQL / SMTP。

`npm run test:integration` 仅接受非团队模式的本地数据库连接，自动创建随机命名的测试库，完成后只删除该测试库。需具备本地 CREATE/DROP DATABASE 权限。不得使用小组配置；代码已加入本地限制。

集成测试和浏览器验收没有修改原项目数据库或小组共享数据库。源码包不含测试数据库文件及真实凭据。
